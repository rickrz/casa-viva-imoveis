# Capturas de tela (prints)

Esta pasta guarda as imagens usadas no relatório e na apresentação.
Coloque aqui os arquivos com os nomes sugeridos abaixo (formato `.png`).

| Arquivo sugerido | O que mostrar |
|---|---|
| `01-home.png` | Página inicial: header fixo, logo, menu e hero |
| `02-menu-mobile.png` | Menu hambúrguer aberto em largura de celular |
| `03-imoveis.png` | Seção de imóveis com os cards e os filtros aplicados |
| `04-formulario.png` | Formulário de contato preenchido e a mensagem de sucesso |
| `05-lia.png` | Janela da Lia respondendo a uma pergunta sobre um imóvel |
| `06-lia-fora-do-escopo.png` | Lia recusando educadamente um assunto fora do escopo |
| `07-admin.png` | Painel de contatos com o resumo por status |
| `08-api-health.png` | Resposta de `GET /api/health` no navegador |
| `09-banco.png` | Tabelas `imoveis` e `contatos` no Neon (ou no `psql`) |
| `10-deploy.png` | Site publicado no Render, com a URL na barra de endereços |

## Como capturar

1. Rode a API (`python app.py`) e abra <http://127.0.0.1:5000>.
2. No Windows, use **Win + Shift + S** para recortar a área desejada.
3. Salve com o nome da tabela acima, dentro desta pasta.
4. Para o print mobile, use o modo responsivo do navegador (F12 → ícone de celular).

> As imagens são opcionais para o código, mas ajudam muito na nota de
> documentação e na apresentação.
